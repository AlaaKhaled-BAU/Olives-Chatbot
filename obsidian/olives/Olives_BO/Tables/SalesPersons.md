# SalesPersons

## Business Purpose
The central commercial personnel registry — stores sales representatives, supervisors, delivery drivers, promoters, and sales managers. Key columns include `ID` (salesman identifier used across transactional documents), `Parent` (points to supervisor's `SalesPersons.ID` in the organizational tree), `SalesPersonType` (role code decoded via `SystemCodes`), and `PositionID` (organizational position linking to workflow inbox and route assignments). Queryable via `t.SalesPersons`.

## Chatbot semantics
(Query `t.SalesPersons` — scoped by session CompanyID via `t.` views.)

| User / Arabic intent | Column(s) | Filter / rule | Notes |
|----------------------|-----------|---------------|-------|
| المناديب التابعين للمشرف | `Parent`, `SalesPersonType` | `Parent = @SupervisorID` OR `SalesPersonType = 4` | Self-referencing tree (`Parent` points to supervisor `ID`) |
| المشرفين (Supervisors) | `SalesPersonType` | `SalesPersonType = 3` | Decoded via `SystemCodes.SalespersonType` |
| مندوب مبيعات (Salesmen) | `SalesPersonType` | `SalesPersonType = 4` | Van and pre-sales representatives |
| سائقي التوصيل (Drivers) | `SalesPersonType` | `SalesPersonType = 7` | Delivery distribution crew |
| موظف موقوف / فعال | `IsSuspended` | `IsSuspended = 0` (Active), `1` (Suspended) | Employment / operational status |
| ربط المندوب مع سير الموافقات | `PositionID` | Join `t.WF_SubLog` / `t.Positions` | Connects salesman to approval position inbox |
| اسم المندوب | `Name` | Text | Primary display name (Arabic or English) |

**Hierarchy note:**
The organizational tree is maintained via `Parent`. In procedural code, `Fun_GetSalesmanTreeByID(@CompNo, @ID)` traverses this recursively, where supervisors (`SalesPersonType = 3`) have subordinate salesmen (`SalesPersonType = 4`).

## Grain & keys
- **PK**: `ID` (integer salesman number)
- **Tenant key**: `CompanyID`
- **Self-reference**: `Parent` → `SalesPersons.ID`
- **FKs**: `PositionID` → [[Positions]](ID), `GroupID` → [[SalesPersonsGroups]](ID), `UserID` → [[Users]](ID)

## Pipeline
Maintained in Back Office personnel management screens (`Pro_SalesPersons`). Synced to mobile devices and stamped onto all transactional headers (`OrdersHeaders`, `TransactionsHeaders`, `Receipts`, `LogActionTransaction`).
