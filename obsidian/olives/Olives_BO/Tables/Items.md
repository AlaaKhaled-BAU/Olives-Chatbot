# Items


## Business Purpose
The master product and merchandise catalog in Olives_BO. Defines all sellable, returnable, and inventoried items across the organization, including internal product codes (`ItemCode`), descriptions (`Name`, `ForeignName`), default selling unit (`UnitID`), category hierarchy (`CategoryID`, `GroupID`, `ClassID`), tax types, barcodes, and active lifecycle flags (`IsSuspended = 0`).
- **Catalog Lookup**: Used across all transactional engines to display item names and descriptions when users ask about sales, returns, stock, or price list details.
- **Hierarchy Links**: Categorized into product families via `ItemsCategories` (`CategoryID`), `ItemsGroups` (`GroupID`), and `ItemsClasses` (`ClassID`).

## Chatbot semantics
(Query `t.Items` — scoped by session CompanyID via `t.` views.)

| User / Arabic intent | Column(s) | Filter / rule |
|----------------------|-----------|---------------|
| البحث عن صنف بالاسم أو الكود | `ItemCode`, `Name`, `ForeignName` | `Name LIKE N'%اسم الصنف%'` أو `ItemCode = @Code` |
| الأصناف النشطة / الموقوفة | `IsSuspended` | `IsSuspended = 0` (نشط وقابل للبيع) أو `1` (موقوف) |
| تصنيف الصنف / العائلة | `CategoryID`, `GroupID`, `ClassID` | Join `t.ItemsCategories` على `CategoryID` |
| الوحدة الافتراضية للصنف | `UnitID` | Join `t.ItemsUnits` على `UnitID` |
| باركود الصنف | `Barcode` | البحث بواسطة الباركود الدولي أو الداخلي |

**Do not confuse with:**
- `t.PriceListDetails` (actual selling prices per customer tier / unit).
- `t.SalesPersonItemsBalance` (current stock carried on a salesman's vehicle).
- `t.StoresBalances` (central warehouse inventory levels).

## Grain & keys
- **Grain**: One row per master product / SKU (`ItemCode`).
- **Composite PK**: `CompanyID`, `ItemCode`.
- **Tenant Key**: `CompanyID`.

## Pipeline
ERP Master Data Sync / BO Item Setup Screen → `Items` (plus `ItemsUnitsDetails` for multi-unit packaging conversion) → Synced to mobile devices via `OT_SendItemsInfo`.

## Common Issues

- **Duplicate barcodes**: Multiple items sharing same barcode — POS picks wrong item
- **Price mismatch**: Sell price in Items differs from PriceListDetails — customer charged wrong amount
- **Stock discrepancy**: QtyInAllStores differs from sum of StoreBalances — run CALCITEMBALANCE
- **Missing units**: Item has no valid ItemUnits — cannot be sold
- **Tax config wrong**: IsTaxExempt flag incorrect — ZATCA/legal reporting mismatch
