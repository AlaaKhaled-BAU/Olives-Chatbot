Known Issues
- Symptom: Opening the Customers tab and editing any record throws "A generic error occurred in GDI+".
- Cause: The web app pool identity cannot write to the image/temp path under the IIS web root (GDI+ needs write
  access to save/process customer images such as barcodes, photos, or signatures).
- Resolution: Grant full control (read/write/modify) to the IIS web root folder (C:\inetpub\wwwroot, or the
  application's published wwwroot directory) for the users / app pool identity running the site. After applying
  permissions, recycle the application pool and retry editing the customer.
