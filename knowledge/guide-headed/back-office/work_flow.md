# 9.2 Work Flow - Work Flow Functions Report
Through this following window especially made for work flow functions , you can issue a report in PDF format to
show you work flow requests during a specified date frame and their status .
From the left window you choose the date
frame from the drop down lists then you
choose the function of the work flow ,
finally you choose the status by selecting
the button Approve for approved work
flows or Reject for rejected work flows,
having done that you press Preview which
will pop up a new window containing the
report in PDF format as shown below.

# 9.3 Work Flow - Customers WF Functions Auto Approve
In some occasions you may find it suitable to over ride the step were the supervisor grants the salesman the per-
mission to proceed with his exceed and you need to automatically grant him the permission once he submits it for
certain customers of your choice you can do so using this following window, all you need to do is select the func-
tion and a list of assigned and unassigned customers would appear for that particular function, you can either
right check the box to allow the auto approval or uncheck an already checked box to go to the standard work flow
function procedure were the supervisor would grant the permission, finally you would need to press the Update
button to save the results.
