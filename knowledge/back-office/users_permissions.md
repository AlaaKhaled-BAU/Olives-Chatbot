11.1 Users & Permissions -Users & Permissions
As we mentioned in a previous section of this guide our back office System is a multi user system, you can have
unlimited number of users for the same back office, you can determine, however, the authorities that each spe-
cific user can have when he uses the system, for example you can have him view parts and prevent him from
viewing other parts of the system, or you can have him look at a part without having the privilege of making any
changes and so on, and this is usually controlled by the admin user of the back office only to control other back
office users actions.

11.4 Users & Permissions—User Company Branch link
From this window you must assign the back office user to his designated branch , unless you do this the user will
only have access to blank pages all over the system, so it is a very important issue.
From this window see image 304-A You choose the
user and then link him to his company branch by
checking the box beside the branch you want to as-
sign him and clicking update , in case you need to
assign another user to same branch you just click the
copy to user button and a new small window will
appear from which you choose the intended new user
to copy same assignment to through the check box
and clicking copy see image 304-C below.
