Introduction :
Olives Sales Field Automation System is a solution to manage and control salespersons Sales
& other transactions operations in a live Sales Field Environment , It mainly consists of two
parts ; a back office application (Olives) and a front office application (OSFA) , The back office
application (Olives) is used by management to manage and fully control the salespersons
performance in live sales field in a fully automated method, whereas front office (OSFA) is an
android based application that is used by a salesman, The use of the system has many ad-
vantages over manual sales such as minimizing cost of client’s sales management , by avoid-
ing too many personnel in Data Entry or other related tasks, minimizing manual data entry
errors to near zero by using a standard database structure and content that can be updated
regularly and consequently reducing a salesperson manual writing errors , in addition the cli-
ent using the system will have faster implementation of Sales process in live sales field, the
system also utilizes the no duplication feature that is a privilege of using a computer SQL Da-
tabase structure.
Who Is this Guide for ?
This system guide is intended for those individuals who are going to use and implement Ol-
ives Field Automation System, while Back office application (Olives) section is intended to
offer fundamental information about usage for Client’s Management and Accounting de-
partments, front office application (OSFA) section is intended to offer all information needed
for a sales man to make different sales transactions in live sales field such as sales invoices ,
sales orders, return orders, surveys, etc.
About This User Guide
Our approach in preparing this User Guide was to get right to the point where the user is in-
volved without trying to dig deep into Technical issues concerning the system functionalities
which are not related to regular system users. Due to the nature of diversity of menus and
sub menus this guide focuses more on the fundamental functions that the user needs to be
familiar with in order to use this system’s Back Office and front Office Applications both prac-
tically and effectively .
